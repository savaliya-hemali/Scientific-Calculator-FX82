# Scientific Calculator

Project done for The Odin Project course AND based in the classic [Casio fx-82MS calculator UI](https://p.turbosquid.com/ts-thumb/4Q/F77cPn/T41VndR2/05/png/1581691738/1920x1080/fit_q87/059ce59bfa6884543d7416a32bf5f41b7dc5069e/05.jpg).

## Features

- ON/OFF
- Sum
- Subtraction
- Multiplication
- Division
- Exponential
- Delete
- Clear
- ANS
- Worked-example recorder: record a run of key presses, name it, and replay it
  step by step (each key lights up as it is pressed). Examples are kept in the
  browser's local storage, so they survive a reload.

## Tech Stack

JavaScript, HTML, CSS
